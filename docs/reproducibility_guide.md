# Reproducibility guide

A reviewer should be able to identify the starting point, data provenance, transformations,
analysis, and outputs.

1. Preserve raw data only when licensing and privacy permit.
2. Record source, access date, license, unit, and variable definitions.
3. Separate raw inputs, processed data, code/notebooks, tables, and figures.
4. Use relative project paths rather than local computer paths.
5. Pin essential package versions when the project is final.
6. Restart and run all notebooks.
7. State the order for reproduction and expected outputs.
8. Explain access and reconstruction when data cannot be shared.
