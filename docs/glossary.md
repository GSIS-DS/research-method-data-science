# Glossary

- **Branch:** separate line of repository development.
- **Code:** an instruction to a computer; in qualitative research, a label applied to evidence.
- **Colab:** browser service for running notebooks.
- **Commit:** named saved repository version.
- **Data provenance:** documented origin and history of data.
- **Git:** software that records file versions.
- **GitHub:** online service for Git repositories.
- **Notebook:** document containing text, code, and outputs.
- **Repository:** project folder plus version history.
- **Reproducibility:** ability to recreate results from a documented starting point.
- **Research design:** plan linking a question, evidence, method, and claim.
- **Theme:** higher-level pattern developed from qualitative codes/categories.
