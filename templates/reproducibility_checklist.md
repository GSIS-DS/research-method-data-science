# Reproducibility checklist

- [ ] Starting point and run order are stated.
- [ ] Data provenance, license, and access are documented.
- [ ] Raw, processed, code, and output areas are distinguishable.
- [ ] No credentials, private data, or local absolute paths appear.
- [ ] Notebooks restart and run all.
- [ ] Expected outputs and package requirements are stated.
- [ ] Non-shareable data have access/reconstruction instructions.
