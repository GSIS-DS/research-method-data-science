# Week 04 concept note

## Guiding problem

How does a review build an argument rather than a list?

## Core idea

The research question determines what evidence is relevant and which method can support the
intended claim. This week focuses on **literature synthesis, gaps, frameworks** and uses Thursday's **synthesis and proposal workshop** to
make the decision visible, testable, and documented.

## Before accepting a result

1. State the claim in plain language.
2. Identify the evidence and how it was produced.
3. Name the strongest assumption.
4. Check an alternative explanation or interpretation.
5. Record what the evidence cannot establish.
