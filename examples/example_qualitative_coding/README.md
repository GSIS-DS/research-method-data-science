# Worked miniature qualitative coding example

Use `data/sample/fictional_interview_excerpts.csv`. For E01, an initial code might be
`confuses Drive and GitHub`. Together with E05 (`hidden session dependency`), a category could be
`unclear storage and execution state`; a cautious theme might be `visible workflow checks help
students locate reproducibility failures`. This theme is illustrative, not a finding about real students.

## Reflexivity prompts

What expectation did you bring to the text? Which excerpt challenged it? What alternative code
could another researcher defend? What is lost when five excerpts are separated from a real context?

## Ethical-risk checklist

- [ ] Evidence is fictional or approved for use.
- [ ] No participant can be identified.
- [ ] Consent/access conditions are documented.
- [ ] Quotations do not reveal sensitive context.
- [ ] Interpretation does not exceed the evidence.
