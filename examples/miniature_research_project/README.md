# Miniature research project: income and life expectancy in six fictional countries

**Question:** Within this fictional six-country teaching dataset, how is income per person associated
with life expectancy? This is a descriptive association, not a causal claim.

## Literature map

This miniature example uses illustrative placeholders (`Author A (Year)`) to demonstrate structure,
not real scholarship. A real project must replace them with located, read, and verified publications.
Themes would include material resources, public institutions, and limits of cross-country comparison.

## Data and method

The data are [wholly fictional and documented](../../data/sample/mini_country_indicators_README.md).
The notebook plots the six observations and estimates a simple linear association. With a tiny,
constructed sample, the result demonstrates workflow only.

## Findings and limitations

The constructed values show a positive pattern. They cannot support claims about real countries,
causality, populations, or precise uncertainty. Region, measurement, selection, and many omitted
factors would matter in real research.

## Reproduce

Open [the notebook](analysis.ipynb), run from top to bottom, and confirm the figure is recreated.
The notebook uses a repository-relative path in GitHub/Colab.
