# Literature evidence matrix example

Fields should include full citation, research question, data/context, method, central finding,
limitation, project relevance, theme/debate, and verified original source.

## Good synthesis

`Author A (Year)` and `Author B (Year)` offer different explanations for the same pattern. The first
emphasizes institutional access, while the second emphasizes individual resources. Because both use
cross-sectional evidence, neither resolves change over time. The project therefore asks whether the
relationship persists across periods and treats causal language cautiously.

## Weak synthesis

`Author A (Year)` studies access. `Author B (Year)` studies resources. `Author C (Year)` has useful
results. These papers show the topic is important.

The good example compares claims, evidence, and limitations to build a gap. The weak example is a
list of summaries. Placeholders are explicitly fictional; replace them with real, verified sources.
