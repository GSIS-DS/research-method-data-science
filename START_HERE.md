# Start here: first-week checklist

You can complete this route in a browser. No terminal or software installation is required.

## 1. Confirm a Google account

1. Open [Google Accounts](https://accounts.google.com).
2. Sign in. This lets Colab save your notebook in Google Drive.
3. **What you should see:** your profile icon.
4. If not, use account recovery or ask the instructor about an alternative.

## 2. Create or sign in to GitHub

1. Open [GitHub](https://github.com) and select **Sign up** or **Sign in**.
2. GitHub stores and displays the course project and its version history.
3. **What you should see:** your profile icon at the upper right.
4. If not, check your email/password and browser privacy settings.

## 3. Choose a professional username

1. Choose a short name you can use in academic or job applications.
2. Avoid student numbers, birth dates, jokes, and private information.
3. **What you should see:** a profile address ending in your username.
4. Already have a suitable account? Keep it; a new account is unnecessary.

## 4. Verify your email

1. Open GitHub's verification email and select **Verify email address**.
2. Verification enables normal account features.
3. **What you should see:** confirmation on GitHub.
4. No email? Check spam and request another from GitHub settings.

## 5. Open the course repository

1. Open the [course repository](https://github.com/GSIS-DS/research-method-data-science).
2. A **repository** is a project folder plus its saved version history.
3. **What you should see:** the course title and this README.
4. A 404 page usually means the repository is not public yet or you lack access.

## 6. Open the preparation notebook

1. Open the [readiness notebook in Colab](https://colab.research.google.com/github/GSIS-DS/research-method-data-science/blob/main/notebooks/preparation/python_colab_readiness.ipynb).
2. **What you should see:** a page with text and code boxes called cells.
3. If it fails, sign in to Google, allow pop-ups, and retry in Chrome or Edge.

## 7. Run one code cell

1. Select the triangular Run button beside the welcome-message cell.
2. This asks the temporary Colab computer to execute that cell.
3. **What you should see:** `Welcome to TIC3002!`
4. If a connection prompt appears, select **Connect**, then run again.

## 8. Change a value and rerun

1. Replace `Student` with your name inside quotation marks.
2. Run the cell again.
3. **What you should see:** a greeting containing your name.
4. A red error often means a quotation mark was deleted; restore both marks.

## 9. Save a personal copy

1. Select **File → Save a copy in Drive**.
2. This saves your own editable copy in Google Drive.
3. **What you should see:** `Copy of` in the notebook title.
4. If unavailable, confirm you are signed in to Google.

> GitHub is not Google Drive. Saving in Colab/Drive does not update GitHub.

## 10. Complete the readiness check

Run the final checklist cell and answer its three short questions. **What you should see:** all checks
marked `True`. If one is `False`, reread the nearby instruction or use
[troubleshooting](docs/troubleshooting.md).

## 11. Confirm submission location

Open Cyber Campus and find TIC3002. **What you should see:** the course page. Cyber Campus is the
official submission location unless a specific assignment states otherwise. Do not upload work to
the public course repository.

## Five-minute successful-setup test

- [ ] Notebook opened in Colab.
- [ ] Welcome cell ran.
- [ ] Name changed and new greeting appeared.
- [ ] Personal copy saved in Drive.
- [ ] You can explain that the Drive copy did not change GitHub.
