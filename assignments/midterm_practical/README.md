# Midterm practical assessment

The midterm assesses independent application of course workflows and is worth 25%. Actual questions,
datasets, grading keys, and solutions are instructor-controlled and are not published here.

## Preparation

Review question–method alignment, literature/source verification, data inspection, interpretation,
privacy, and reproducibility. Practice explaining each decision. AI is prohibited unless explicitly
authorized in the official assessment arrangement.

## Submission and criteria

Follow the official Cyber Campus and in-class instructions. Criteria and permitted resources will be
stated in the released assessment. No public repository submission is required by this overview.
