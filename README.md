Learn to turn a social-science question into a credible, ethical, reproducible study. The research
question determines the method; Python and GitHub support the research rather than define it.
Prior programming experience is helpful but not required.

> This is not a Python-from-zero course. If coding is new to you, begin with the
> [preparation notebook](notebooks/preparation/python_colab_readiness.ipynb) and
> [Colab beginner guide](docs/colab_beginner_guide.md).

## Weekly rhythm

- **Tuesday:** concepts, research design, worked examples, and discussion.
- **Thursday:** research studio, practical work, peer feedback, and project development.

## Assessment overview

| Component | Weight |
|---|---:|
| Research workflow labs and participation | 10% |
| Literature review and research proposal | 15% |
| Midterm practical assessment | 25% |
| Qualitative research exercise | 15% |
| Final examination assignment—individual research project | 35% |
The assessment components total 100%. There is no separate graded peer-review component.

## Course map

Weeks 1–4 build the question, literature synthesis, and proposal; Weeks 5–6 develop qualitative
design and analysis; Weeks 7–13 develop design, data, and quantitative evidence; Weeks 14–16
integrate, present, defend, revise, and submit the complete individual study.

## Open a notebook in Colab

1. Open a notebook link and select the **Open in Colab** badge.
2. In Colab, select **File → Save a copy in Drive** before editing.
3. Run cells from top to bottom. Saving in Drive does **not** update GitHub.
